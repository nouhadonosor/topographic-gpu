# Topographic

WebGL renderer for generating topographic-style terrain images and video.

[![](https://img.shields.io/badge/nouhadonosor.github.io%2Ftopographic--gpu-2ea44f?style=for-the-badge)](https://nouhadonosor.github.io/topographic-gpu/)

## Usage

Serve the project locally, then open the displayed address in a browser:

```sh
make serve
```

The default server listens on `http://127.0.0.1:8000`.
